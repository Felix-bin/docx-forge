# 模板准备规范

[English](../template-preparation-guide.md) | [中文](./template-preparation-guide.md)

---

docx-forge 把内容编译**进你的 Word 模板**。按本规范准备的模板可以顺利入库；依赖手工格式的模板会得到一份满是 `needs-manual` 的体检报告。入库从不修改原文件，所以你可以逐个、逐步地整理模板。

## 1. 目录结构

每个模板一个文件夹：

```text
my-templates/
└── company-report/
    ├── company-report.docx      # 或 .dotx
    ├── README.md                # 用途和规则（见 §6）
    └── sample.docx              # 可选：一份真实填写过的范例
```

## 2. 所有结构性内容都用样式

| 内容 | 应该 | 不要 |
|---|---|---|
| 标题 | 应用 `标题 1`…`标题 4` 或你自己命名的标题样式 | 加粗 + 放大字号 |
| 正文 | 一个正文样式，如 `正文文本` 或自定义的 `正文` | 用 `Normal` 再手工调缩进和间距 |
| 项目符号 / 编号列表 | 列表样式，或绑定了列表的段落样式 | 手打 `•` 或 `1.` |
| 表格和图片题注 | `题注` 或专用题注样式 | 居中加粗的普通段落 |
| 表格 | 表格样式（标题行、边框、底纹） | 手工给单元格加边框 |
| 引用、说明、警示 | 专用段落样式 | 斜体或加底纹的正文段落 |

**小技巧**：在 Word 中打开“样式”窗格，关闭“显示预览”，打开“样式检查器”；每个结构性段落都应显示一个命名样式，并且没有“+”直接格式。

## 3. 把标题编号链接到标题样式

如果标题带编号（如 `一、` / `（一）` / `1.` / `（1）`，或 `1` / `1.1` / `1.1.1`）：

1. 开始 → 多级列表 → **定义新的多级列表**。
2. 对每一级设置编号格式，点击 **更多** → **将级别链接到样式** → 选择对应的标题样式。
3. 绝不把编号手打进标题文字里。

入库会读取这个绑定；手打的编号会被报告为缺陷。

## 4. 标出正文插入位置

在生成内容应插入的位置，放一个只包含 `{{正文}}`（或 `{{body}}`）的段落。它之前和之后的所有内容（封面、版头、落款、附录）都视为固定区域，原样保留。

对于没有固定区域的 `format` 模板，锚点可以是正文中唯一的段落。

## 5. 标出可变字段

对每份文档都不同的值（标题、日期、发文字号、主送机关），任选一种方式：

- 在要放该值的段落里以纯文本输入占位符 `{{字段名}}`，如 `{{标题}}`、`{{发文字号}}`、`{{日期}}`；或
- 使用 Word 内容控件（开发工具 → 纯文本内容控件），并把 **标记（Tag）** 设为字段名。

每个占位符要一次性输完，中途不要改格式，保证它位于同一个 run 内。

## 6. 为每个模板写一份 README

```markdown
# 公司报告模板
- 用途：向管理层提交的季度报告和项目报告
- 文体：报告
- 固定区域：封面、保密页脚
- 字段：{{标题}}、{{部门}}、{{日期}}
- 规则：标题不超过 3 级；每个表格都要有题注
- 不得改动：封面版式、页脚文字
```

README 会成为模板的使用说明；这里写的规则在规划阶段会被遵守。

## 7. 页面设置与分节

- 页边距、纸张大小、页码格式都在模板中设置好。
- 如果前置部分用罗马数字页码、正文用阿拉伯数字，请在模板里用**分节符**隔开，并在正文节设置“起始页码为 1”。
- 各节不同的页眉页脚要在模板中设好；编译器不会创建它们。

## 8. 交付模板前的检查清单

- [ ] 每个标题都使用标题样式，没有手打编号
- [ ] 多级列表各级已链接到标题样式
- [ ] 正文、列表、题注、表格、引用样式齐全
- [ ] 有且只有一个 `{{正文}}` 锚点段落
- [ ] 可变字段是 `{{字段}}` 占位符或带标记的内容控件
- [ ] 已写 README
- [ ] 可选：一份填写好的范例文档
