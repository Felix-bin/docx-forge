# docx-forge

[English](./README.md) | [Chinese](./README_CN.md)

Write natively styled, editable Word documents **into your own templates** from a chat with an AI agent.

docx-forge plans the document's argument first, writes it section by section in a constrained Markdown dialect (DocMD), and compiles it into your Word template: every paragraph uses a template style, every heading number, caption, cross-reference, and table of contents is generated by Word itself, and a live browser preview shows the compiled document as it is written.

> **Status: P0 — charter and scaffold.** The design documents and contracts exist; the scripts, routes, and preview are not built yet. See the [roadmap](./docs/roadmap.md).

## Why

AI-written Word files usually look right and break on the first edit: fake headings, typed numbers, a hand-made table of contents, inconsistent terms. docx-forge treats your template as the mold and Word's own mechanisms as the only source of structure, so the result keeps working when you continue editing it.
